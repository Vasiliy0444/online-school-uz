# Метод скана рекламы в Meta Ad Library

Как собрать и разметить узбекоязычную рекламу инфопродуктов, которую Meta показывает в Узбекистане.
Первый прогон — 15.09.2026, данные в [03-reklama-meta/](03-reklama-meta/).

## Что нужно

- Сборщик: [`../tools/facebook-ads-library-mcp/`](../tools/facebook-ads-library-mcp/) — код на коммите `ea3c877`,
  проверен на безопасность 15.09.2026 (см. `SOURCE.md`).
- Окружение: `~/.venvs/fb-ads-library` (Python 3.11, crawl4ai 0.9.3, fastmcp, pytest) и Chromium из кеша Playwright.
  Если окружения нет:
  ```bash
  python3 -m venv ~/.venvs/fb-ads-library
  ~/.venvs/fb-ads-library/bin/pip install "fastmcp>=2.6.1" "crawl4ai>=0.7.0" pytest
  ~/.venvs/fb-ads-library/bin/python -m playwright install chromium
  ```
- Ни ключей, ни аккаунта Meta не нужно. В аккаунт не входить.

## Шаги

1. **Проверить разборщик** — родные тесты сборщика и тесты разметки:
   ```bash
   cd "tools/facebook-ads-library-mcp" && ~/.venvs/fb-ads-library/bin/python -m pytest tests/ -q
   cd "research/03-reklama-meta" && ~/.venvs/fb-ads-library/bin/python -m pytest test_classify.py -q
   ```
2. **Пробный прогон** — 5 запросов с `pilot=1` в `keywords.csv`:
   ```bash
   ~/.venvs/fb-ads-library/bin/python sweep.py --pilot
   ```
   Принимается, если карточки пришли минимум по 4 запросам из 5 и среди рекламодателей есть знакомые имена.
3. **Полный скан** — все запросы из `keywords.csv`, фоном около двух часов:
   ```bash
   ~/.venvs/fb-ads-library/bin/python sweep.py
   ```
   Уже скачанные запросы пропускаются: скан можно прервать и продолжить. Перед новым сканом
   старую папку `raw/` переименовать в `raw-ГГГГ-ММ-ДД/`, иначе ничего не скачается.
4. **Разметка:**
   ```bash
   python3 classify.py
   ```
   Пишет `ads.csv`, `ads_uz_info.csv`, `advertisers.csv`, `niches_x_funnels.csv`, `summary.json`.
5. **Разбор** — по скиллам `competitor-ad-intelligence`, `ad-to-landing-page-auditor`, `landing-page-intel`
   и фреймворкам `~/.claude/agents/tw-creative-analyzer.md` и `tw-pattern-finder.md`. Итог — `ИТОГ.md`.

## Грабли, на которые уже наступили

- **Язык интерфейса.** Без явного `Accept-Language` Meta отдала headless-браузеру страницу на французском,
  и разборщик не нашёл ни одной карточки: он ищет английские метки «Library ID», «Started running on»,
  «Sponsored». Поэтому в `sweep.py` своя копия функции рендера с английским интерфейсом.
  Лог неудачного прогона — `03-reklama-meta/sweep-pilot1-french.log`.
- **Код 403 — это нормально.** Meta отвечает headless-браузеру кодом 403, но карточки отдаёт.
  Успех считается по разобранным карточкам.
- **Прокрутка дорогая.** Без прокрутки — около 23 карточек за 21 секунду, с 12 прокрутками — 32 карточки
  за 52 секунды (запрос «mobilografiya»). В основных нишах ставим 6 прокруток, в остальных — 3.
- **Фильтр страны.** `is_targeted_country=true` даёт ноль даже у явно узбекских брендов. Используется
  `country=UZ&is_targeted_country=false` — объявления, которые показывались в Узбекистане.
- **Поиск идёт по тексту объявления**, а не по названию страницы. Рекламодателя без нужного слова в тексте
  этот метод не найдёт.
- **Мусор в тексте карточки.** Разборщик захватывает ссылки редиректа (`taxid=` в них принимался за «такси»)
  и подвал страницы («English (US)»). `classify.py` чистит текст перед разметкой.
- **Суммы в объявлениях.** «Oyiga $1000 daromad» — обещание дохода, а не цена курса. Цена берётся только рядом
  со словами про цену (narxi, to'lov, chegirma, atigi), доход — отдельным полем `income_claim_max_uzs`.

## Ограничения данных

- Снимок активной рекламы на дату скана. Расходов и показов Meta для коммерческой рекламы вне ЕС не показывает.
- `ads_using_creative` — сколько объявлений использует один креатив. Это признак масштаба, а не бюджета.
- Разметка — правила по ключевым словам. Спорные объявления проверяются глазами по ссылке на объявление.
- Автоматический сбор из библиотеки объявлений может противоречить правилам Meta. Здесь разовый исследовательский
  сбор публичных данных небольшого объёма, без входа в аккаунт.

## Как сравнивать сканы

Повторять раз в 2–4 недели с тем же `keywords.csv`. Сравнивать по `advertisers.csv`: кто появился, кто пропал,
у кого выросло число объявлений, какие объявления идут дольше 30 дней.
