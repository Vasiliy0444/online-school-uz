# Метод глубокого разбора рекламы конкурентов

Как повторить разбор «денежных» школ: вся реклама в Meta и Google, креативы с кадрами и расшифровкой, публичные лендинги,
цены и офферы, HTML-отчёт. Первый прогон — 16–17.09.2026, данные в [05-razbor-konkurentov/](05-razbor-konkurentov/),
итог — [05-razbor-konkurentov/ИТОГ.md](05-razbor-konkurentov/ИТОГ.md).

## Что нужно

- Окружение `~/.venvs/fb-ads-library` (crawl4ai 0.9.3, Chromium) — сбор Meta, снимки лендингов.
- Системный `python3` с Pillow, requests, jsonschema, mlx-whisper; `ffmpeg`, `yt-dlp`, `pdftotext`.
- Скиллы: `watch` (кадры и расшифровка), `web-archive-scraper`, `landing-page-intel`, `ads-creative`, `ads-landing`,
  `ad-to-landing-page-auditor`; методики `tw-creative-analyzer`, `tw-pattern-finder`; свой `skachat-kreativy`.
- Медиа — в `~/Data/online-shkola-uz/05-razbor-konkurentov/` (не на Рабочем столе: его синхронизирует iCloud). Около 4 ГБ на 9 школ.
- Аккаунтов, ключей, куки и прокси не нужно. Ноутбук — на зарядке и с открытой крышкой: сон рвёт загрузки.

## Шаги (все скрипты — в `05-razbor-konkurentov/`, продолжают с места остановки)

1. **Мастер-список и отбор:** `candidates.py` → `meta_collect.py ad/page` → `pages_aggregate.py` → `schools_build.py`
   (+ `manual_decisions.py`) → `socials.py` (Instagram — вручную во встроенном браузере, не чаще 5 профилей за 20 минут)
   → `money_signals.py`. Утверждённый список школ — константа `APPROVED` в `money_signals.py`.
2. **Реклама Meta:** `stage2_run.py` (курсор по дате запуска + скачивание медиа), затем добор пропусков
   `meta_collect.py gapfill --page-id …` и `media_download.py --raw-dir raw/meta/gapfill/<page>`; таблицы — `ads_meta_build.py`.
3. **Кадры и расшифровка:** `stage3_run.py` (или `frames_transcribe.py --school …`): mlx-whisper large-v3, `language="uz"`.
4. **Google Ads:** `google_collect.py probe`; если капча — сайт Transparency Center во встроенном браузере: домены школ
   с регионом Узбекистан и поиск рекламодателя по названию; итог — `02-reklama/ads_google.csv`, `05-otchet/google_status.json`.
5. **Лендинги:** `landings_find.py` (8 источников; `--merge --skip …` — добавить новые ссылки без повторного Wayback) →
   `landings_snapshot.py --per-school 30` → `oferta_fetch.py` → `landings_snapshot.py --index-only`;
   скриншоты первого экрана разобранных страниц — `landings_snapshot.py --reshoot`.
6. **Разметка креативов агентами:** `tag_batches.py --batch 30` → агент на порцию по `04-razbor/prompts/tag_creatives.md`
   → `validate_json.py tags …`. Слепая проверка: `tag_agreement.py --make-batch 3`, агент пишет в `tags_check/`, затем `tag_agreement.py`.
7. **Разбор лендингов агентами:** по `04-razbor/prompts/analyse_landings.md` → `validate_json.py landing …`.
8. **Сводка и отчёт:** `aggregate.py` → `report_data.py` (выводы — `05-otchet/findings.template.json`, числа только
   через подстановки фактов) → `verify_report.py` (числа, цитаты, ссылки) → публикация папки `05-otchet/`.

## Грабли, на которые уже наступили

- **ID страницы в библиотеке Meta ≠ ID профиля.** Нужен `view_all_page_id` из JSON объявления.
- **Прокрутка библиотеки → «Rate limit exceeded».** Собираем только документ страницы (до 30 объявлений), паузы 25–45 с.
- **Фильтр `start_date[max]` накопительный, за загрузку — не больше 30 объявлений.** Курсор по дате запуска теряет объявления,
  если между соседними границами их больше 30: недобор ровно равен сумме превышений. Лечится `gapfill` — дробление окна по дате
  по счётчику «~N results». Массовый запуск в один день (у Shahlo ~110 объявлений 5 сентября) не добирается.
- **Ссылка `?id=` без `country=UZ`** открывает библиотеку со страной подключения и пишет «No ads match».
- **`http://fb.me/` без адреса** в объявлении — мгновенная форма Meta, а не сайт.
- **Одно видео — одна папка.** Одинаковый файл качается один раз в папку первого объявления; представитель креатива может быть
  другим (`media_of` ищет папку с кадрами). У динамических объявлений несколько роликов в одной папке — файлы кадров и
  расшифровки второго и следующих роликов пишутся с суффиксом `-slot<N>`.
- **Скриншот лендинга после прокрутки** снимал подвал вместо первого экрана — снимаем без прокрутки, `wait_until="load"`.
- **Оферты с якорями** (`#tariffs`) — одна страница; якоря отрезаются.
- **Узбекская речь:** автоопределение языка путает с казахским и азербайджанским — только `language="uz"` с подсказкой на латинице.
  Расшифровки черновые: разметчик исправляет явные ошибки распознавания в хуке, а сырой фрагмент оставляет доказательством.
- **Google Transparency Center** отвечает капчей Python-клиенту с этого IP; обходить нельзя — проверка вручную на сайте.
- **Агенты-разметчики** иногда поднимают ложную тревогу о «чужих кадрах» (похожие варианты роликов) — проверять по md5,
  и могут сами запускать подагентов — в инструкции прямой запрет.

## Правила, которые не меняются

Только публичные данные: без входа в аккаунты, форм, ботов и оплат; блокировки и капчи не обходим; одно задание Meta за раз;
имена и фото учеников не записываем; креативы — только для внутреннего анализа, отчёт — приватный.
