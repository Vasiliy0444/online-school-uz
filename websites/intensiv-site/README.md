# «ИИ на заказ» — лендинг бесплатного интенсива

Посадочная страница под рекламу в Instagram: человек читает оффер и по кнопке уходит в Telegram-бот за 3 бесплатными уроками.
Три варианта дизайна для A/B-теста, тексты у всех одинаковые.

## Адреса

| Адрес | Что открывается |
|---|---|
| https://vasiliy0444.github.io/ai-na-zakaz-intensiv/ | Случайный вариант A, B или C. Браузер запоминает его: при повторном заходе человек видит тот же вариант |
| …/ai-na-zakaz-intensiv/a/ | A — «Лаймовый билборд» |
| …/ai-na-zakaz-intensiv/b/ | B — «Ночное бенто» |
| …/ai-na-zakaz-intensiv/c/ | C — «Белая мозаика» |
| …/?v=b | Принудительно вариант B, удобно для проверки |
| …/privacy/ | Политика конфиденциальности (черновик) |

## Как устроен A/B-тест

- **Чище всего — тест в Meta Ads.** Сделайте три группы объявлений с одинаковыми креативами, в каждой своя ссылка: `/a/`, `/b/`, `/c/`. Meta сама разделит аудиторию и покажет, где заявка дешевле.
- **Общий адрес.** Для органики, ссылки в профиле и посевов подходит корень. Там вариант выбирается случайно, примерно поровну.
- **Где смотреть результат.** Каждая кнопка ведёт в бот с меткой в параметре `start`: `va-…`, `vb-…` или `vc-…`. Бот сохраняет метку, и по первым двум символам понятно, с какого варианта пришёл человек. Если подключён пиксель Meta, событие `Lead` тоже передаёт вариант.

### Метка для бота

Формат: `v{вариант}-{utm_source}-{utm_campaign}-{utm_content}`. Без UTM — `v{вариант}-direct`. Пример: `va-instagram-sep_test-hook_math_v2`.
Telegram принимает в `start` до 64 символов и только `A–Z a–z 0–9 _ -`, поэтому:
- **В UTM пишите латиницей.** Кириллица из метки удаляется.
- Части метки обрезаются: источник до 10 символов, кампания до 18, контент до 20.
- Если в адресе UTM нет, берутся последние сохранённые в браузере.

### Заголовок под хук рекламы

Если в `utm_content` есть одно из слов `compare`, `math`, `now` или `zero`, первый экран покажет заголовок под этот хук. Тексты согласованы, лежат в `src/config.js`:

| Ключ | Заголовок |
|---|---|
| compare | Такси, трейдинг, Uzum или ИИ: на чём реально заработать $1000 в месяц в 2026 году |
| math | $1000 в месяц на ИИ — это не пассивный доход, а 3–4 заказа от бизнеса |
| now | ИИ собирает сайт за вечер, а бизнес платит за него от 2,5 до 5 млн сум |
| zero | Можно ли с нуля заработать на ИИ, если ты студент и не программист? |

Например: `…/a/?utm_source=instagram&utm_campaign=sep_test&utm_content=hook_math_v2`.

## До запуска рекламы

1. `src/config.js` → `BOT_USERNAME`: username бота без @. Пока поле пустое, кнопки показывают подсказку «Бот ещё не подключён».
2. `src/config.js` → `PIXEL_ID`: ID пикселя Meta. Без него пиксель не загружается.
3. Блок «Кто ведёт» (`src/template.html`, секция `#hosts`): заменить заглушки `[фото]`, `[роль…]`, `[факт]` на настоящие факты и фото.
4. Подвал и `src/privacy.html`: юрлицо (ИП или ООО, ИНН) и контакт для обращений. Политику проверить у юриста.
5. Бонус «Топ-10 каналов, где найти клиентов на ИИ-услуги»: собрать до запуска, он обещан на странице.
6. После замены заглушек: `INDEXABLE = true` в `src/config.js`, чтобы страницу можно было индексировать.
7. С января: «в 2026 году» → «в 2027 году» (шаблон, конфиг, `scripts/make-og.mjs`).

## Команды

```bash
npm install
npm run dev          # разработка: http://localhost:5173/ai-na-zakaz-intensiv/
npm run build        # сборка в docs/ (её и отдаёт GitHub Pages)
npm test             # тесты метки для бота
npm run check:texts  # сверка текстов с согласованным прототипом
npm run preview      # собранный сайт: http://localhost:4174/ai-na-zakaz-intensiv/
npm run qa           # автопроверка трёх вариантов на 7 ширинах (нужен запущенный preview)
npm run og           # картинка превью public/og.png
```

`check:texts` работает внутри рабочей папки проекта: согласованные тексты лежат рядом, в `research/13-lending-intensiva/`.

## Как устроен код

- `src/template.html` — одна разметка на все варианты. `scripts/build-pages.mjs` собирает из неё `index.html`, `a/`, `b/`, `c/` и `privacy/`.
- `src/styles/tokens.css` — цвета и шрифты трёх тем (`html[data-variant]`). `components.css` — компоненты, `base.css` — основа.
- `src/main.js` — метка для бота, кнопки, липкая кнопка на телефоне, пиксель. `src/lib/attribution.js` — сборка метки, покрыта тестами.
- `src/anim.js` — анимации GSAP. Грузятся лениво и не включаются при «уменьшить движение».
- `scripts/postbuild.mjs` — CSP мета-тегом (GitHub Pages не даёт задать заголовки) и предзагрузка шрифтов.
- `DESIGN.md` — дизайн-система «Лайм + чернила». `superdesign/design_iterations/` — первые варианты первого экрана.

## Деплой

GitHub Pages берёт сайт из ветки `main`, папка `/docs`. Порядок: `npm run build`, затем закоммитить `docs/` и сделать push.
