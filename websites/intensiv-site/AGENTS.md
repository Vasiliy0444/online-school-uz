# Правила для агентов (Codex, Claude Code)

Лендинг бесплатного интенсива «ИИ на заказ». Подробности — в `README.md`, дизайн — в `DESIGN.md`.

## Главное

- **Тексты не придумывать.** Все тексты согласованы с Васей и лежат в `../../research/13-lending-intensiva/LANDING_PROTOTYPE_RU.md` (блок 3 — `ЧЕРНОВИКИ.md`). Новый текст на страницу — только после согласования.
- **Числа не придумывать.** Каждое число на странице — из прототипа, у каждого там указан источник. Цифр без источника не добавлять.
- **Разметка у трёх вариантов одна** (`src/template.html`), различаются только CSS-переменные в `src/styles/tokens.css`. Меняешь текст — он меняется во всех вариантах сразу, так и должно быть.
- **Одна кнопка на всю страницу**: «Забрать 3 бесплатных урока →». Не добавлять формы, меню, таймеры, «осталось N мест» и выдуманные отзывы.
- **Мобильная версия важнее десктопа.** На 375×812 и 360×640 кнопка первого экрана должна быть видна без прокрутки.

## Перед коммитом

```bash
npm test && npm run build && npm run check:texts
npm run preview   # в отдельном окне
npm run qa        # 21 проверка: без горизонтальной прокрутки, кнопка в первом экране, нет ошибок консоли и CSP
```

Все проверки должны быть зелёными. `docs/` коммитится: его отдаёт GitHub Pages.
