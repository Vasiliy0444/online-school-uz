Какие данные обрабатываются

На сайте нет форм заявки, личного кабинета и оплаты. Если вы пишете на указанную почту, я получаю ваш адрес электронной почты, имя, если вы его указали, и содержание письма. Эти данные нужны, чтобы ответить вам и продолжить переписку по вашему вопросу. Рекламную рассылку по ним я не отправляю.

Сайт размещён на GitHub Pages. При посещении страницы GitHub фиксирует IP-адрес для безопасности сервиса. Для загрузки шрифтов сайт обращается к Google Fonts; при этом Google может получать технические данные о запросе. Подробнее об обработке данных: политика GitHub и политика Google.

Основания обработки и защита

Письма обрабатываются для ответа на ваше обращение и, если вопрос связан с курсом, для действий до заключения договора. Технические данные обрабатываются для работы и безопасности сайта. При передаче данных используются защищённые соединения; доступ к почте ограничен учётной записью.

Кому передаются данные

Сайт обслуживает GitHub Pages. Для переписки используется Gmail от Google. Данные, обрабатываемые этими сервисами, могут находиться за пределами страны посетителя. Я не передаю письма рекламодателям и не продаю персональные данные.

Переписка хранится, пока нужна для ответа и решения вопроса. Если письмо связано с договором, спором или обязанностью по закону, оно может храниться дольше — в пределах необходимого срока. Сроки хранения технических данных у GitHub и Google определяются их политиками.
