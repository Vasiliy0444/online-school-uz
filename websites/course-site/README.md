# ИИ на заказ — программа курса

Статический сайт с темами рабочей программы онлайн-курса и тремя тарифами: самостоятельный $99, с куратором $149, с гарантией $249. Исходный документ программы — `research/10-programma-kursa/programma-kursa.md` в локальном проекте. Цены и запрос на тариф с гарантией предоставлены владельцем проекта в чате 27.09.2026.

Публикация: GitHub Pages из ветки `main`, корень репозитория. Страница не обещает заработок и не принимает оплату. Краткая оферта (`offer.html`) охватывает тарифы, гарантию и возвраты; текущая политика конфиденциальности (`privacy.html`) описывает информационный сайт без оплаты. Перед открытием оплаты нужно разместить полные условия конкретного заказа (дата старта, срок доступа, платформа, итоговая цена и валюта списания), обновить политику под фактический платёжный сервис и проверить обязательные требования для стран продаж.
