## ⚠️ Главное правило проекта: у каждого числа есть ссылка

- **Каждое число, имя блогера, школы и цена — со ссылкой на источник в том же абзаце.**
  Для рекламы источник — ссылка на объявление `facebook.com/ads/library/?id=…`.
- Что без ссылки — помечается «не проверено» прямо в тексте.
- Заявления самих игроков (число учеников, доходы учеников, «95% трудоустройства») — со звёздочкой *, это самоотчёт.
- **Цифры аудитории из поисковых сводок завышены в разы**: у PDP Academy сводка давала 268 тыс. подписчиков,
  в канале было 8 170. Подписчиков Telegram проверять на `t.me/<канал>`, Instagram — по мета-описанию профиля.
- Понижающие оговорки («оценка», «не подтверждено», «данных нет») обязаны пережить любую редактуру.

## Что нельзя делать без спроса

- **Регистрироваться на вебинары, нажимать Start в ботах, писать блогерам, оставлять контакты в формах.**
  Воронки изнутри проходит Вася сам, со своего аккаунта.
- **Объявлять решение go/no-go.** Ресёрч даёт аргументы, решение принимает Вася.
- **Менять файлы в `skills/` и `tools/`.** Это копии с GitHub с указанием коммита в `SOURCE.md`.
  Обновление — новая копия, новый коммит и новая проверка безопасности.
- **Переписывать закрытые исследования** `research/01` и `research/02`. Дополнять можно.
