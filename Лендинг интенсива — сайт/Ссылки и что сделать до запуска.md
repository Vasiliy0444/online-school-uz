## Как запускать A/B-тест

- В Meta сделать 3 группы объявлений с одинаковыми креативами и ссылками на /a/, /b/, /c/. Метки UTM — латиницей.
- В боте считать старты по метке: `va-…`, `vb-…`, `vc-…` — это вариант страницы. После варианта идут источник, кампания и объявление.
- Хуки: если в `utm_content` есть `compare`, `math`, `now` или `zero`, заголовок меняется на согласованный вариант под этот хук.

## До запуска рекламы

1. Username бота — в `src/config.js`, поле `BOT_USERNAME`. Пока бота нет, кнопки показывают «Бот ещё не подключён».
2. ID пикселя Meta — там же, поле `PIXEL_ID`.
3. Факты и фото в блоке «Кто ведёт» (сейчас там заглушки) — задача CURSOR-w6ef.
4. Юрлицо в подвале и в политике конфиденциальности, политику проверить у юриста.
5. Собрать бонус «Топ-10 каналов» (список каналов ждёт твоего «ок») — задача CURSOR-z17g.
6. Проверить переход из Instagram в бот на живых iPhone и Android.
7. После замены заглушек — `INDEXABLE = true` в `src/config.js`.

Пересборка: `npm run build`, потом commit и push — GitHub Pages обновится сам.
