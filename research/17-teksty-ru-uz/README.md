## Как пересобрать после правок
```bash
python3 build_pools.py                       # русский md из pools_ru.json
python3 check_uz.py pools_uz_final.json      # проверка перевода: числа, эмодзи, апострофы, кириллица
python3 build_pack_uz.py pools_uz_final.json # xlsx для ассистента
```

## Как делали перевод
переводчик (Opus) → редактор-носитель (Opus, ИИ) → два слепых обратных перевода (Opus и Sonnet видели только узбекский) → скрипт. Живой носитель текст ещё не читал.

## Что решить до запуска
- Кнопка Meta: в текстах стоит «Batafsil». В реальных узбекских объявлениях так кнопку не называют; редактор советует нейтральную фразу «Ro‘yxatdan o‘tish uchun yuqoridagi tugmani bosing».
- Пул 2, лонгрид: «5 услуг», перечислено 4.
- Пул 8: «bilak kuchi bilan emas, bilim bilan» может задеть семьи мигрантов. Оба слепых переводчика это отметили.
- Пул 9: хук с недоверием («опять $1000?») и название курса «С 0 до первой $1000» в одном тексте спорят друг с другом; читается как противоречие.
- Пул 9 можно запускать только с настоящим проданным сайтом и скриншотом оплаты (CURSOR-hakw).
- «Было 3 млн сум»: среди тарифов на доске такой суммы нет (699 990 / 1 649 990 / 13 999 990).
- «Осталось 26 мест из 100»: число должно быть настоящим и обновляться.
- V2 (инсценировка уведомлений) вне пулов.
