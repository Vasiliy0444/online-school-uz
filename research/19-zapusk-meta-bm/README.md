# Запуск Meta в кабинете БМ «Uzbekustan RK»

Что реально собирается в рекламном кабинете бизнес-менеджера: кампании, группы и объявления недели 1, с какими креативами и текстами и с какими ID в Meta. Основа — план 15.10 из `research/18-struktura-kampaniy-i-piksel/`.

**Что читать:**
1. `01-ПЛАН-ЗАПУСКА.md` — структура, бюджеты, настройки, решения Васи, отличия от 15.10.
2. `РЕЕСТР-КРЕАТИВОВ-И-ТЕКСТОВ.md` — каждый креатив: файлы, тексты, группа, имя объявления, метка бота, ID в Meta.
3. `03-ЖУРНАЛ-ЗАЛИВКИ.md` — что сделано в кабинете.
4. `04-ПЕРЕСБОРКА-1В1.md` — если пропали страница или кабинет: пересборка 1в1 без подтверждений (`rebuild.py`, воркфлоу `meta-rebuild-1v1`).

**Как пересобрать и проверить:**

```bash
python3 build_launch.py            # launch.json, registry.json, реестр
python3 check_launch.py            # 0 ошибок — можно заливать
python3 check_launch.py --online   # плюс проверка ссылок raw, по которым Meta скачивает файлы
```

**Источники данных:**
- структура по аудиториям — `v2_plan.json` (план, раздел 10);
- креативы — `research/16-kreativy-meta/АКТУАЛЬНЫЕ креативы УЗ — Meta/`;
- каталог креативов и общие настройки — `research/18…/build_structure.py`;
- тексты — `research/17-teksty-ru-uz/pools_uz_final.json`;
- ID — `ids.json` и `meta_ids.json`.

Медиа Meta скачивает по ссылкам `raw.githubusercontent.com/Vasiliy0444/online-school-uz/<коммит>/<путь>`, поэтому на время загрузки репозиторий должен быть публичным.
