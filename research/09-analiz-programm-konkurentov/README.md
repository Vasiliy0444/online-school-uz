# Анализ программ конкурентов — index

Разбор 7 обучающих программ про заработок на нейросетях и 6 программ из других ниш (Wildberries, бьюти,
Reels-продюсирование), присланных Васей файлами и ссылками 26–27.09.2026. Задача: найти модули,
лид-магниты и формулировки результата, которые можно позаимствовать в свою программу.

**Начни с [00-VYVODY-I-REKOMENDACII.md](00-VYVODY-I-REKOMENDACII.md)** — там синтез по всем 13 файлам,
привязанный к нашей воронке из `../08-miro-kastdevy-segmenty/voronka-i-metodika/`. Остальные файлы ниже —
подробный разбор каждого источника по отдельности, на них синтез ссылается.

## Как это делалось (на случай вопросов к цифрам)

- PDF читались напрямую через постраничное чтение; один файл (`1 (1).pdf`, 102 МБ) превышал лимit
  инструмента — был разбит на 5 частей по ~40 страниц, прочитан целиком по частям.
- `.pptx`-файлы инструмент не читает напрямую (бинарный формат) — каждый был распакован (это обычный
  zip-архив), текст слайдов извлечён из XML, картинки слайдов (где программа/модули оформлены как
  графический дизайн, а не текст) просмотрены напрямую как изображения. Ни один слайд не пропущен.
- Часть работы (2 больших PDF, 3 презентации из смежных ниш) выполнена параллельными фоновыми агентами —
  каждому передан точный список файлов/страниц и структура, что извлекать; агенты писали сразу в целевые
  файлы. Сайты разобраны напрямую через браузер.
- Каждый файл начинается с комментария-источника — путь к оригиналу или ссылка, что прочитано полностью
  или частично. При сомнении в цифре или цитате — сверяйте с оригиналом по этому комментарию.
- Цены не переводились по единому курсу автоматически — в синтезе (`00-VYVODY-I-REKOMENDACII.md`, раздел 5)
  есть отдельная таблица сравнения в долларах с указанием курса на дату расчёта.
