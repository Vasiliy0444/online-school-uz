## Чем отличаются программы

| | По Тимочко | По Дымшакову |
|---|---|---|
| Название | «Сайты, боты, заказчики» | «Первый заказ на ИИ» |
| Обещание | «Научись с нуля за 60 дней делать сайты и ботов с ИИ, находить заказчиков и брать 3–4 заказа по $300 в месяц» — по образцу «Сайты, деньги, 2 ствола» | «Первый оплаченный заказ от малого бизнеса за 4 недели: сайты и боты на нейросетях без программирования и вложений» — формула «результат + инструмент + срок + без страха» |
| Срок | 60 дней, 8 модулей — по одному в неделю, в финале защита дипломного кейса | 4 недели, 7 модулей — по два в неделю, в финале демо-день. У Дымшакова первый поток — до месяца |
| Логика модуля | темы → материалы «через проблему» («не знаешь, сколько брать → калькулятор цены») → результат; у каждого модуля своя неделя | результат → задания → ключевые вопросы → файлы; у каждого модуля 2–3 задания |
| Когда ищем заказчиков | с 4-й недели, первый заказ — цель 5-й недели | со 2-го модуля, то есть с первой недели |
| Бесплатный вход | 4 шага: гайд «первый сайт на бесплатном ИИ», 3 урока в боте, калькулятор «сколько заказов закроют мой платёж», секретный эфир | 1 лид-магнит, как велит Дымшаков: 3 урока в боте и живой эфир |
| Над модулями | путь по неделям, «Если ты … → твой результат» для 4 сегментов, 6 фишек — каждая против одной проблемы | трансформация А → Б (уровень 3 — система), «для кого» для 5 сегментов, 6 бонусов, иерархия «результат результатов → результат → промежуточные» |
| Объём | больше: 32 файла, десятки по городам, челлендж, чат заказов | меньше: контент только под задания, по правилу «не нагрузить контентом» |
| Где закрыты 57 болей | модулями — 39, лид-магнитами — 20, фишками — 11, форматом — 9 | модулями — 41, лид-магнитом — 13, блоком «для кого» — 12, бонусами — 10, форматом — 10 |

Счёт в последней строке — сколько болей упоминают это место в карте болей; одна боль часто закрыта в двух-трёх местах. В обеих программах только условиями оплаты закрывается Б56 «проценты — харам». Цену курса (Б55) программа лишь подкрепляет расчётом, сколько заказов окупают обучение, — сама цена за Васей.

## Как пересобрать

```bash
python3 check.py
python3 render.py --previews /tmp/preview
```

Текст правится только в MD. После правки — `check.py` (0 ошибок), потом `render.py`. Сборщик пишет «проблем вёрстки: 0», если текст влез во все блоки. Заголовки и жирные метки MD (`## Модуль N.`, `**Содержание модуля:**`, `**Материалы:**`, `**Результат после модуля:**`, `**Задания:**` и другие) не переименовывать: по ним собирается PDF.

## Как делали

1. Реестр болей собран из 5 сегментов ЦА, кастдевов, сводки ресёрча, троек по Ханту, брифа рынка и разборов рекламы и конкурентов. Полнота сверена с картой болей прошлой программы `research/10-programma-kursa/karta-boley.md`: все 54 её боли здесь есть, плюс 6 новых.
2. Две программы писали два агента параллельно, каждый со своим скиллом: `prototipirovanie-produkta-timochko` и `prototipirovanie-produkta-dymshakov` + `dym-offer-dymshakov`. Работы друг друга и прошлые программы из `research/10-*` агенты не видели.
3. Редактура, проверка `check.py`, дизайн и просмотр каждого слайда — после.

## Чего нет и что решает Вася

- Цены, тарифы, гарантия, рассрочка без процентов, язык уроков, лица команды — у каждой программы свой список «Решения за Васей».
- Цены на сайты и ботов, налог для самозанятых, способы получить оплату из-за рубежа, работа с телефона — «не проверено», список в «Проверить до запуска».
- Учеников, кейсов и отзывов нет: школа не запускалась. Цифра $1000 в месяц везде — расчёт «3–4 заказа по $300», а не доход выпускников.
- Итоговую программу из двух собирать после решения 9 развилок между авторами (задача CURSOR-k189.7, файл `~/.claude/skills/prototipirovanie-produkta/references/razvilki.md`).
