## 4. Скрипт скачивания и расшифровки

- `_scripts/run.py` — качает Яндекс Диск (публичный API), YouTube (yt-dlp), подхватывает видео из Telegram по длительности (`telegram_videos` в `manifest.json`) и файлы из папок (`watch_folders`), расшифровывает `mlx_whisper` (`mlx-community/whisper-large-v3-turbo`, `language="ru"`, `condition_on_previous_text=False`). Лог — `_scripts/log.txt`, состояние — `_scripts/status.json`. Продолжает с места остановки, готовые расшифровки не повторяет.
- **Сейчас в Терминале крутится старая копия** (запущена в 17:03). Она не может скачать Яндекс Диск: у python.org-Python 3.11 нет корневых сертификатов (`CERTIFICATE_VERIFY_FAILED`). В новой версии `run.py` это исправлено через `certifi`, плюс подбор JS-рантайма для yt-dlp и автоперезапуск при изменении `run.py`.
- **Первым делом в Claude Code:**
  1. Дождись, пока в логе появится `готово … Урок 13` (или проверь `status.json`), чтобы не прервать расшифровку.
  2. Останови старую копию и запусти новую в фоне:
     ```bash
     pkill -f "_scripts/run.py"
     cd "$HOME/Desktop/CURSOR/БИЗНЕС/Онлайн школа УЗ/research/07-prototip-produkta/_scripts"
     nohup caffeinate -i python3 run.py >> run.out 2>&1 &
     ```
     Если снова `CERTIFICATE_VERIFY_FAILED` — `open "/Applications/Python 3.11/Install Certificates.command"` или `pip3 install certifi`.
  3. Яндекс Диск ≈ 1,4 ГБ → расшифровка ≈ 15–25 мин (Блок 2 на 101 мин занял 20 мин).
  4. `Материалы и дз.docx` → текст: `textutil -convert txt -stdout "<файл>"`. В них, вероятно, ссылки на шаблоны — открыть и выгрузить.
  5. Когда всё готово — поставить `"finish_when_done": true` в `manifest.json`, скрипт завершится сам.
