# Прототип продающего сайта по Дымшакову

Источники: Блок 2 интенсива (Б2, 2021) и урок 4.4 «Создание прототипа продающего сайта основной программы» (У4.4, 8:34) с шаблоном Notion (Ш-сайт). Таймкоды — по расшифровкам.

## Что это и зачем
- Продажник — итог прототипирования: весь прототип программы должен уместиться в продажник [У4.4 00:07:49–00:08:15].
- Форма вторична: сайт, статья-лонгрид, пост или серия сторис; «суть важнее формы» [Б2 01:05:04; У4.4 00:00:20–00:00:51].
- Те же смыслы потом идут в продающую часть вебинара или марафона, в посты и сторис [У4.4 00:00:51–00:01:00; В 00:01:06–00:01:18].

## Как работать с таблицей блоков [У4.4 00:01:11–00:07:29]
- Сайт делится на блоки. У блока: **тип** (основной — всегда, усилитель — по возможности), **статус**, текст-прототип и **референсы дизайна** («хоть 20 референсов»).
- Статусы: прототип готов → в дизайне → дизайн готов → в сборке → готово. Блоки можно раздать разным людям, даже разным дизайнерам.
- Прототип делается понятным дизайнеру: расположение, кнопки, пометки, выделенные смыслы [У4.4 00:03:33–00:04:21].
- Первый сайт — из основных блоков, потом добавлять усилители [У4.4 00:06:44–00:07:42].

## Порядок блоков в Блоке 2 [Б2 01:05:22–01:06:46]
1. Название и оффер (первый экран) → 2. Результат → 3. Для кого → 4. Автор → 5. Формат → 6. Программа (часто поднимают выше) → 7. Тарифы → 8. Усилители (отзывы, кейсы, доп. материалы) → FAQ.

## Основные блоки (шаблон модуля 04)
| Блок | Задача | Что внутри |
|---|---|---|
| Первый экран | ключевая информация | дескриптор («авторский курс …»), название, оффер, кнопка, старт, длительность, формат |
| Для кого | актуализировать боль, показать решение, сразу разделить по сегментам | сегмент → «Если вы …» (ситуация, боль) → «Результат: …» |
| Программа | раскрыть детали продукта | модули из прототипа программы в финальном виде |
| Формат программы | показать, как и какими инструментами достигается результат | пункты формата (платформа, материалы, чат, разборы) и **в каких тарифах каждый пункт есть** |
| Автор | «продать» компетентность, статус, регалии | фото, достижения, результаты |
| Тарифы | пакеты участия | 3 тарифа; у каждого три цены (вебинар / со скидкой / основная); общий список наполнения с зачёркнутым; остаток мест (пример: ∞ / 80 из 100 / 2 из 20); кнопки «Купить» и «Купить в рассрочку»; таймер; дата окончания продаж |
| Подвал и реквизиты | юридическая и контактная информация | реквизиты, оферта, контакты |

## Усилители
| Блок | Задача |
|---|---|
| Эмоциональная цитата | переходный блок: акцент на главном смысле продукта (у автора — «один запуск может изменить всё» и история автора*) |
| Результат программы | 3–5 главных результатов по итогу |
| Отзывы и кейсы | все социальные доказательства; на первом потоке, пока кейсов нет, можно без него; когда есть — сделать максимально качественно |
| FAQ | закрыть основные возражения |
| Гарантии | гарантии разного уровня (возврат в течение 14 дней; возврат при отрицательном результате) — повышают конверсию |
| Как это работает: этапы и карта | визуализировать путь к результату |
| Команда и доп. спикеры | лояльность за счёт профессионализма команды |
| Цифры и статистика | для аудитории «с аналитическим складом ума» |
| Сертификаты, награды | доверие |

## Примеры из шаблона (кратко, своими словами)
- **Первый экран** «Запуск на Миллион»: авторский курс по запускам; оффер «как создать и запустить онлайн-проект с максимальным результатом»; кнопка «Принять участие»; старт, 10–12 недель, онлайн.
- **Для кого** — 4 сегмента: блогеры и эксперты, уставшие от недобросовестных продюсеров (→ смогут сами быть продюсером); продюсеры и проджекты без фундамента (→ запуски проще и системнее); начинающие «продюсеры» на поверхностных фишках (→ поймут суть); новички (→ фундамент, направление и первые результаты).
- **Формат программы**: платформа с доступом на год и доп. материалы — во всех тарифах; чат и онлайн-разборы раз в 2–3 недели — только стандарт и VIP.
- **FAQ**: сколько времени в неделю (от часа, в своём темпе); можно ли повысить тариф (в течение месяца после старта, доплатив разницу); нужен ли свой проект для прохождения.
